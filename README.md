# ◈ Digital Avatar — MVP

Прототип веб-приложения для развития сотрудников через **цифрового аватара**:
сотрудник строит профиль, видит **карту движения** (вертикальный рост по грейдам + горизонтальные переходы между ролями) и ведёт **индивидуальный план развития**.

> 🚀 Чистый HTML/CSS/JS без сборки. Идеально для GitHub Pages.

---

## 🎯 Что внутри MVP

| Модуль | Что делает |
|---|---|
| **Профиль** | Аватар, уровень, XP, текущая позиция, навыки (Hard/Soft), прогресс до следующего грейда |
| **Карта роста** | Сетка `Направление × Грейд` (30 позиций). Подсветка: 🟪 текущая, 🟩 вертикальный рост, 🟦 горизонтальный переход. Клик → разрыв в навыках |
| **План развития** | Цели с прогрессом. Закрытие цели = +XP и +5 к навыку. Можно добавлять свои цели |
| **Активность** | Лента событий: рост навыков, смена позиции, достижение целей |
| **Геймификация** | Уровень аватара от XP, `+` к любому навыку, смена emoji-аватара по клику |

---

## 🧱 Модель данных

```
Track (направление) × Grade (грейд) = Position (позиция)
```

- **6 направлений**: Backend, Frontend, Data, DevOps, Product, QA
- **5 грейдов**: Junior → Middle → Senior → Lead → Principal
- **Каждая позиция** содержит требования к навыкам (0–100)
- **Готовность** = среднее по `min(1, текущий / требуемый)` по всем требованиям
- **Переход на позицию** доступен при готовности ≥ 85%

Всё описано в `data.js` — легко расширять.

## 🖥️ Запуск локально

```bash
# Вариант 1: открыть напрямую
open index.html

# Вариант 2: локальный сервер (рекомендуется)
python3 -m http.server 8000
# → http://localhost:8000
```

## 🌐 Деплой на GitHub Pages

1. Создайте репозиторий `digital-avatar` и загрузите файлы.
2. **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Через минуту: `https://<username>.github.io/digital-avatar/`.

Файл `.nojekyll` (пустой) уже в корне — чтобы GitHub не трогал статику.
